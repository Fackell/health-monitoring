Отримати практичні навички розширення функціональності вебзастосунку, реалізації обміну даними в реальному часі, створення інтерактивних компонентів, візуалізації статистики, оптимізації продуктивності, налаштування PWA та автоматизованого тестування.

## 4. Виконання роботи

### 4.1. Обмін даними в реальному часі

Підключено Socket.IO Client до наявного серверного Socket.IO. Реалізовано підключення з використанням JWT-токена, обробку подій створення, оновлення та видалення активностей.

Для підтримки актуальності даних використано інвалідацію кешу TanStack Query. Додано очищення обробників подій та відключення сокета при завершенні роботи відповідного компонента.

### 4.2. Система сповіщень

Створено Zustand store для зберігання сповіщень. Реалізовано компонент NotificationBell з відображенням кількості непрочитаних повідомлень, переглядом списку, позначенням повідомлень прочитаними та очищенням списку.

### 4.3. Інтерактивні компоненти

Додано:
- модальне вікно підтвердження видалення активності;
- компонент вкладок Tabs;
- компонент SearchableDropdown із пошуком та вибором значень.

Компоненти використовують відповідні ARIA-атрибути для покращення доступності.

### 4.4. Статистика та Drag and Drop

На Dashboard реалізовано статистичні картки з кількістю завантажених записів, загальною тривалістю та витраченими калоріями.

Додано графік тривалості фізичної активності за останні сім днів за допомогою Recharts.

За допомогою DnD Kit реалізовано перетягування статистичних карток із підтримкою клавіатурної взаємодії.

### 4.5. Оптимізація продуктивності

Реалізовано відкладене завантаження сторінок за допомогою React.lazy та Suspense.

Підключено Rollup Plugin Visualizer для аналізу структури, розміру та стиснення JavaScript-бандла.

Після оптимізації основний JavaScript-файл має розмір близько 381,74 kB, а окремий файл Dashboard — близько 464,64 kB до стиснення.

### 4.6. PWA та SEO

Налаштовано Vite PWA з автоматичною реєстрацією Service Worker.

Створено Web App Manifest із назвою, описом, кольорами оформлення та іконками різних розмірів, включно з maskable-іконкою.

Додано SEO-метадані: мову сторінки, опис, заголовок, Open Graph та theme-color.

Перевірено production-збірку, маніфест і реєстрацію Service Worker у браузері.

### 4.7. Автоматизоване тестування

Налаштовано Vitest із середовищем jsdom та React Testing Library.

Створено тести для компонентів Tabs і SearchableDropdown.

Перевірено відображення елементів, активний стан вкладок, фільтрацію варіантів та обробку вибору.

Результат виконання: 2 тестові файли, 6 успішних тестів.

### 4.8. CI

Підготовлено GitHub Actions workflow для автоматичного виконання ESLint, Vitest та production-збірки frontend після push і pull request.
