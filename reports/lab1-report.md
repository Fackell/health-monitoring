# Звіт до лабораторної роботи №1

**Тема:** Розроблення backend архітектури та основного функціоналу системи моніторингу фізичної активності та здоров'я.

### . Мета роботи

Розробити серверну частину вебзастосунку для моніторингу фізичної активності та показників здоров'я з використанням Node.js, Express.js, PostgreSQL та Prisma ORM.

### 1. Використані технології

- Node.js — серверне середовище виконання JavaScript.
- Express.js — фреймворк для створення REST API.
- PostgreSQL — реляційна база даних.
- Prisma ORM — взаємодія з базою даних.
- bcryptjs — хешування паролів.
- Git та GitHub — контроль версій і зберігання проєкту.

### 2. Виконана робота

1. Створено структуру backend-проєкту.
2. Налаштовано сервер Express.js та обробку JSON-запитів.
3. Налаштовано підключення до PostgreSQL через Prisma ORM.
4. Створено моделі користувачів, фізичної активності, показників здоров'я, цілей, щоденної статистики та тегів.
5. Реалізовано CRUD-операції для користувачів та записів фізичної активності.
6. Додано перевірку вхідних даних та обробку помилок.
7. Реалізовано хешування паролів користувачів.
8. Створено маршрути для перевірки стану сервера та підключення до бази даних.
9. Підготовлено документацію REST API.
10. Перевірено роботу основних endpoint-ів.

### 3. Тестування

Під час тестування перевірено:
- створення, отримання, оновлення та видалення записів;
- отримання списку користувачів та фізичної активності;
- обробку некоректних ідентифікаторів;
- перевірку типу активності та тривалості тренування;
- обробку повторної реєстрації з однаковою електронною адресою;
- перевірку мінімальної довжини пароля;
- повернення помилки 404 для неіснуючих записів.

Результати тестування підтвердили коректну роботу реалізованих операцій та механізмів валідації.

### 4. Висновок

У результаті лабораторної роботи розроблено backend-частину системи моніторингу фізичної активності та здоров'я. Реалізовано REST API, налаштовано роботу з PostgreSQL через Prisma ORM, створено моделі даних та CRUD-операції. Додано валідацію вхідних даних, обробку помилок і хешування паролів. Проєкт опубліковано на GitHub.

Отримані навички роботи з Node.js, Express.js, PostgreSQL, Prisma ORM та Git.
